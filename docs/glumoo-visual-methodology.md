# Glumoo Pinterest 视觉方法论

## 研究来源

- 2026-10-28 在 Pinterest 使用 4 组关键词扫描 117 张不重复参考图，覆盖宠物营养补充剂、彩色宠物品牌企划、自然生活方式摄影和人宠产品互动。
- 对照 Railway 历史记录中的 Glumoo 多巴胺家居、自然窗光、城市公园和露营系列成片。
- 对照 `glumoo-xhs-generation` 技能包能确认的主线：实时六参考、本页矩阵、最高风险证明图、六张正文、七图 QA。技能包未包含其引用的原机 SOP 文件，因此未臆造缺失字段或门槛。

研究过程不把 Pinterest 原图复制到产品素材库。系统只保留归纳后的构图锚点，避免版权、链接失效和无关图片污染产品身份。

## 稳定方法

1. 每套任务只选择一条视觉路线：多巴胺家居商业摄影，或自然窗光/户外生活方式摄影。
2. 开始制作前，根据主题稳定抽取 6 个构图锚点，形成六参考校准矩阵。
3. 第一张封面兼作最高风险证明图，先锁定产品包装、人物、宠物、光线、色彩与景深。
4. 证明图的视觉身份传给后续页面，但每页必须改变机位、景别或动作。
5. 产品是前景品牌锚点，人宠互动是故事主体；产品不能悬浮、变形或抢走全部叙事。
6. 生成图不叠加海报文字、便签或信息卡；图片小字如需发布，按完整 SOP 应在合格照片后单独做文字层。

## 提示词结构

每次 Glumoo 生成按固定顺序组装：

1. 品牌摄影总纲与明确禁止项。
2. 本套唯一视觉路线。
3. 六参考校准矩阵。
4. 当前页导演指令。
5. 产品身份锁与生成前自检。

这套结构分别进入大纲规划和逐页生图，确保文本模型与图片模型使用同一套视觉决策。
