# Glumoo Pinterest 视觉方法论

## 研究来源

- 2026-10-28 在 Pinterest 使用 4 组关键词扫描 117 张不重复参考图，覆盖宠物营养补充剂、品牌企划、生活场景和人宠产品互动。
- 对照 Railway 历史记录中的 Glumoo 室内、城市、居家和户外系列成片。
- 对照 `glumoo-xhs-generation` 技能包能确认的主线：实时六参考、本页矩阵、最高风险证明图、六张正文、七图 QA。技能包未包含其引用的原机 SOP 文件，因此未臆造缺失字段或门槛。

研究过程不把 Pinterest 原图复制到产品素材库。系统只保留归纳后的构图锚点，避免版权、链接失效和无关图片污染产品身份。

## 稳定方法

1. 不预设或判断固定风格类别，不使用关键词把任务塞进“多巴胺、自然、商业、户外”等标签。
2. 参考母库预先组成 12 套无标签六参考矩阵；开始制作前，根据主题稳定选择其中一套。
3. 模型结合用户主题与产品参考图，现场归纳六张的共同色彩、材质、光线、空间、人物关系、产品位置和景深；冲突特征自动舍弃。
4. 第一张封面兼作最高风险证明图，先锁定产品包装、人物、宠物、光线、色彩与景深。
5. 证明图的视觉身份传给后续页面，但每页必须改变机位、景别或动作。
6. 产品是前景品牌锚点，人宠互动是故事主体；产品不能悬浮、变形或抢走全部叙事。
7. 生成图不叠加海报文字、便签或信息卡；图片小字如需发布，按完整 SOP 应在合格照片后单独做文字层。

## 提示词结构

每次 Glumoo 生成按固定顺序组装：

1. 品牌摄影总纲与明确禁止项。
2. 无标签六参考校准矩阵。
3. 当次动态归纳规则。
4. 当前页导演指令。
5. 产品身份锁与生成前自检。

这套结构分别进入大纲规划和逐页生图，确保文本模型与图片模型使用同一套视觉决策。
